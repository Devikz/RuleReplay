# Hackathon contribution and attribution

Project: **RuleReplay**. Team: **Beyond Assertions**. Theme: **Push the Frontier**.

The initial repository contained a README, an MIT license and a Python gitignore. During this implementation session on 2026-10-29, the application, synthetic policies, Java/Python fixtures, tests, benchmark, UI, security boundaries and documentation were authored for this project with Codex assistance under the user's specification. No external financial dataset or proprietary customer code was used. Existing license attribution was preserved.

## Original contributions

- Three-way comparison architecture and deterministic classification with predecessor-policy provenance.
- Synthetic versioned late-fee rules, payment-date migration defect, supporting scenarios and test corpus.
- Independent integer-cent oracle, schema validation, generation receipts, policy snapshots and replay records.
- Meta Muse Wonder adapter and explicit offline generation; Modal execution adapter and bounded harness.
- React workspace, evidence inspection, release summary, export, policy editor and run history.
- Ten synthetic mutants, measured local baselines, metamorphic tests and bounded counterexample reduction.

## Dependencies and services

Core Python dependencies: FastAPI (MIT), Pydantic/Pydantic Settings (MIT), Uvicorn (BSD-3-Clause), HTTPX (BSD-3-Clause), Modal SDK (Apache-2.0). Developer tools include pytest (MIT), Hypothesis (MPL-2.0), Ruff (MIT), pytest-cov (MIT), and uv (MIT/Apache-2.0).

Frontend dependencies: React/React DOM (MIT), Vite (MIT), TypeScript (Apache-2.0), Tailwind CSS (MIT), Lucide icons (ISC), Vitest (MIT), Testing Library (MIT), jsdom (MIT), and Prettier (MIT). Dependency lockfiles preserve resolved packages. Upstream license files remain in installed packages; no dependency has been vendored into the source repository. Validate transitive licensing again before distributing bundled software under new terms.

Meta Model API and Modal are hosted services with their own account terms and billing, distinct from the SDK licenses. No provider account agreement was accepted and no paid service call was made during implementation.

Research references are credited in [RESEARCH.md](RESEARCH.md). Documentation-informed SDK calls and standard protocol use are not claims of inventing those APIs. No third-party paper implementation was copied.
